# bodymake（体づくりアプリ）

iPhoneのホーム画面に置いて使う、体づくりのためのWebアプリです。

## できること

- **食事**: 写真を撮る（または「牛丼並と味噌汁」のように文字で書く）と、AIがカロリーとたんぱく質・脂質・炭水化物を推定。よく食べるものは「お気に入り」から1タップで記録。
- **体**: InBodyアプリの結果画面を「画面収録」でスクロールしながら1回録るだけ（またはスクショをまとめて選ぶ）で、AIが数値を読み取って記録。タニタの体重計は画面を撮るだけ。体重・体脂肪率のグラフ、腹筋が見えるまでの目安。
- **体の写真分析**: 正面・横・後ろの写真から、目標に対して足りない部位と重点的にやるべきことをAIが提案。
- **トレーニング**: 目標・体のデータ・写真分析・これまでの記録・器具をもとに、AIが週2〜4回のメニューを作成。記録すると前回の重さが自動で入り、全セットできたら「重さを上げましょう」と知らせる。
- **1日の目標**: 基礎代謝と方針（引き締め／維持／増量）から、カロリーとたんぱく質の目標を自動計算。

## 費用

すべて無料。AIは Google の Gemini（無料枠）を使います。

- 1日に使える回数に上限があります（通常の使い方なら十分な量）。
- 無料枠では、送った写真や文章がGoogleのAI改善に使われることがあります。体の写真は顔を写さずに撮ってください。

## データの保存場所

記録はすべて**使っているiPhoneの中だけ**に保存されます（ネット上には保存されません）。
設定画面の「書き出す」でバックアップを取れます。

## ファイル

| ファイル | 役割 |
|---|---|
| index.html | 画面の骨組み |
| style.css | 見た目 |
| app.js | アプリの中身（計算・AI・記録） |
| sw.js | 電波がなくても開けるようにする仕組み。**更新したら `CACHE` の数字を上げる** |
| manifest.json / icon-*.png / apple-touch-icon.png | ホーム画面に置いたときの名前とアイコン |
| icon.svg | アイコンの元データ |

## 公開方法（GitHub Pages）

「セリフ稽古」と同じく、GitHubアカウント `totonou-lab` に新しいリポジトリ（例: `bodymake`）を作り、このフォルダの中身をドラッグ＆ドロップでアップロード → Settings → Pages で「main / root」を選ぶ。
公開されるのはプログラムだけで、記録や写真、APIキーは公開されません。
